    76.4 One real example candidate record¶

    Pulled directly from AJpro-merc/exocomet-hunter-data/results/Kepler/KIC_1161345.jsonl (first line), cloned directly on 2026-09-16:

    {"target_id": "KIC 1161345", "t_min": 122.95008577283913, "depth_ppm": 1498.9501060346245,
 "duration_days": 0.9808628563769162, "a_dur": 0.12020535975282774, "a_slope": 0.10042584112591929,
 "ingress_duration_days": 0.2774508311957362, "egress_duration_days": 0.35326642599916624,
 "a_dur_sigma": 0.1672204364056346, "significance": 0.718843715138022,
 "delta_bic": -409.4210857549401, "tau_over_sigma": 2.118670089087749, "signs_agree": true,
 "flagged": false, "periodic": true, "period_days": 7.9912409134324305,
 "vetting_status": null, "vetting_reasons": null}

    Note this specific event is "flagged": false despite tau_over_sigma > 1 — because delta_bic is strongly negative (-409), i.e. the symmetric model fits this event far better than the comet profile, correctly failing the ΔBIC half of the two-condition rule (§45.1). vetting_status/vetting_reasons are null, consistent with §45.5/§58.2 (no Vetter implementation exists). This is real output from KIC 1161345, the star flagged as an open concern in 49_negative_results.md §49.2 — this specific record is one of the ~260 detected events there, and (being unflagged) is not one of the 43 flagged ones driving that concern.
