    EHS-CTS — Exocomet Hunter Scientific & Technical Specification¶

    Master index. Version 1.0 (DRAFT). Reflects repo state as of 2026-09-16, commit 01c2051, plus a real uncommitted working-tree fix — see 59_error_taxonomy.md ERR-006 and SPECIFICATION_STATUS.md.

    This document was built by reading the actual source, configuration, tests, workflows, and session history of exocomet-hunter — not from a generic template. Where a capability does not exist yet, the relevant section says so explicitly using one of: IMPLEMENTED · TESTED · VALIDATED · OPERATIONAL · PARTIAL · PLANNED · BLOCKED · DEPRECATED · UNKNOWN · NOT IMPLEMENTED · UNVERIFIED. Read SPECIFICATION_STATUS.md first for the honest one-page health view before trusting any individual section's depth.

    Vocabulary discipline enforced throughout: never "confirmed" — only "candidate", "candidate event", "exocomet-like morphology", "candidate consistent with an exocomet interpretation". No numeric claim appears without source/method/date, or it's UNVERIFIED.

    Standing infrastructure (repo root / .githooks/, not part of the numbered spec)¶

    • docs/DOCUMENTATION_WORKFLOW.md (repo root, outside this site) — the full per-commit / 20-commit rollup mechanism, setup instructions (git config core.hooksPath .githooks).
    • docs/CHANGELOG_PENDING.md (repo root, outside this site) — per-commit scaffold log (empty until the next commit fires the hook).
    • docs/CHANGELOG.md (repo root, outside this site) — permanent compressed rollup history (empty until the first 20-commit rollup).
    • .githooks/post-commit — the hook itself, executable, tested in an isolated scratch repo.
