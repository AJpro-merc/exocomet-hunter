    35. Code Reference — exocomet.detect¶

    Status: reflects repo state as of 2026-09-16, commit 01c2051 (this package is unmodified in the working tree's uncommitted diff). IMPLEMENTED. Cross-reference: 14_candidate_detection.md, 15_model_fitting.md, 16_statistics.md, 17_uncertainty.md for narrative/design context.

    detect/baseline.py¶

    days_to_cadences(days, cadence_days) -> int¶

    Source: src/exocomet/detect/baseline.py:42-69

    Lines 42–67. Converts a duration in days to a whole cadence count: max(round(days / cadence_days), 1). Raises ValueError if cadence_days <= 0.0.

    odd_window(window, n_points) -> int¶

    Source: src/exocomet/detect/baseline.py:70-92

    Lines 70–90. Clamps window to an odd value in [1, n_points]. Raises ValueError if window < 1.

    rolling_median(values, window) -> FloatArray¶

    Source: src/exocomet/detect/baseline.py:93-105

    Lines 93–103. Centred running median via pandas.Series.rolling(window=odd_window(...), center=True, min_periods=1).median(). Edges are truncated (fewer real points), never padded — see 14_candidate_detection.md §14.1 for the measured 30-70σ false-edge- significance this was found to prevent.

    rolling_baseline(flux, window) -> FloatArray¶

    Source: src/exocomet/detect/baseline.py:106-124

    Lines 106–122. Alias-with-docstring around rolling_median — the local out-of-dip reference level.

    local_noise(flux, baseline, window) -> FloatArray¶

    Source: src/exocomet/detect/baseline.py:125-157

    Lines 125–157. Robust per-cadence sigma: MAD_TO_SIGMA * rolling_median(|flux - baseline|, window), floored at max(global_sigma * 1e-3, np.finfo(np.float64).tiny) to avoid a zero denominator on perfectly flat stretches.

    MAD_TO_SIGMA: float = 1.4826 (module constant, line 39)¶

    Gaussian-equivalent scale factor for a median absolute deviation.

    detect/candidates.py¶

    depth_significance(flux, baseline, sigma) -> FloatArray¶

    Source: src/exocomet/detect/candidates.py:24-31

    Lines 24–29. (baseline - flux) / sigma, positive = dimming.

    find_candidate_events(time, flux, baseline, sigma, config=None) -> list[EventWindow]¶

    Source: src/exocomet/detect/candidates.py:94-168

    Lines 94–168. Main entry point; see 14_candidate_detection.md §14.2 for the full seven-step algorithm (threshold → run-length → merge → edge-guard → expand → disjoint-clamp). Parameters: config: CandidateConfig | None, defaults applied if omitted. Returns: non-overlapping EventWindow list, ordered in time. Notes: fully vectorised except the bounded outward-expansion loop per surviving run (_expand_window), so cost is linear in cadence count.

    _find_runs(mask) -> list[tuple[int, int]] (private, lines 32–40)¶

    Source: src/exocomet/detect/candidates.py:32-42

    Vectorised inclusive (start, end) run detection via np.diff on a zero-padded boolean mask.

    _merge_runs(runs, max_gap) -> list[tuple[int, int]] (private, lines 43–54)¶

    Source: src/exocomet/detect/candidates.py:43-56

    Merges runs separated by <= max_gap cadences.

    _expand_window(time, significance, start, end, recovery_sigma, max_window_days) -> tuple[int, int] (private, lines 57–91)¶

    Source: src/exocomet/detect/candidates.py:57-93

    Grows a run outward on each side while significance > recovery_sigma and the window has not exceeded max_window_days (measured from the run's centre time).

    detect/asymmetry.py¶

    ols_slope(x, y) -> tuple[float, float]¶

    Source: src/exocomet/detect/asymmetry.py:43-76

    Lines 43–74. Ordinary least squares y = a + b x. Returns (slope, slope_err); (nan, inf) if x.size < 3 or zero spread in x.

    locate_minimum(time, flux, window) -> tuple[float, float, int]¶

    Source: src/exocomet/detect/asymmetry.py:77-114

    Lines 77–112. Sub-cadence minimum via a parabola through the deepest cadence and its two neighbours; falls back to the discrete minimum if the three points are collinear or the fitted vertex falls outside the central cadence. Returns (t_min, f_min, index).

    measure_side(time, flux, window, idx_min, t_min, baseline_level, depth, side, config=None, search_bound=None) -> SideFit | None¶

    Source: src/exocomet/detect/asymmetry.py:154-237

    Lines 154–235. Measures one side ("ingress" or "egress") between the half-depth crossing and the minimum. Returns None when the half-depth level is never crossed within the search region, or too few cadences remain to fit a slope (config.min_points_per_side, default 3) — an unmeasurable side is reported as such, never scored on noise.

    _half_depth_crossing(time, flux, idx_min, bound, half_level, direction) -> tuple[float, int] | None (private, lines 115–151)¶

    Source: src/exocomet/detect/asymmetry.py:115-153

    Walks outward from the minimum until flux recovers past half_level, then linearly interpolates the crossing time. None if the flux never recovers within [idx_min, bound].

    compute_asymmetry(ingress, egress) -> AsymmetryResult¶

    Source: src/exocomet/detect/asymmetry.py:238-257

    Lines 238–255. a_dur = (egress.duration - ingress.duration) / (egress.duration + ingress.duration); a_slope = (|ingress.slope| - |egress.slope|) / (|ingress.slope| + |egress.slope|). Both 0.0 if their respective denominator is <= 0.

    measure_event(time, flux, baseline, window, target_id, config=None) -> DipEvent¶

    Source: src/exocomet/detect/asymmetry.py:258-309

    Lines 258–309. Full per-event measurement: locate minimum, measure both sides (searching up to config.search_padding_factor × window.n_points cadences beyond the detected window on each side), combine into AsymmetryResult if both sides measurable. Returns a DipEvent with asymmetry=None and a populated unmeasurable_reason string if either side could not be fitted — never raises for an unmeasurable event.

    detect/comet_detector.py¶

    AsymmetricDipDetector(config: PipelineConfig | None = None)¶

    Source: src/exocomet/detect/comet_detector.py:28-117

    Lines 28–118. Implements the Detector protocol (core/interfaces.py). name = "asymmetric-dip". Deliberately thin — "owns no science of its own; it sequences the baseline estimation, candidate finding, geometric measurement and statistical scoring implemented in the sibling modules" (module docstring).

    • baseline_and_noise(lc) -> tuple[FloatArray, FloatArray] (lines 48–54) — converts config.baseline.median_window_days/noise_window_days to cadences via days_to_cadences(days, lc.cadence_days) and calls rolling_baseline/ local_noise. Source: src/exocomet/detect/comet_detector.py:48-55
    • detect(lc) -> list[DipEvent] (lines 56–70) — finds candidate windows, measures each into a DipEvent. Unmeasurable events are still returned (see measure_event above). Source: src/exocomet/detect/comet_detector.py:56-71
    • score(event, lc) -> EventScore (lines 72–85) — recomputes the baseline for the parent light curve, calls periodicity_flag and score_event. Note: this recomputes baseline/noise and the periodogram independently, at real cost, if called per-event rather than via .run(). Source: src/exocomet/detect/comet_detector.py:72-86
    • run(lc) -> list[CandidateRecord] (lines 87–117) — the efficient path, Source: src/exocomet/detect/comet_detector.py:87-117 overriding the base Detector.run(): computes baseline/noise and the periodogram once for the whole light curve, then loops once over detected windows to build each CandidateRecord(event=..., score=...). Returns [] immediately if no candidate windows are found (skips the periodogram computation entirely in that case).

    Constructor seeds self._rng = np.random.default_rng(config.runtime.rng_seed) (default seed 42) — the RNG instance is held per-detector, so successive .run() calls on the same detector instance produce different bootstrap draws each time (the RNG's internal state advances), while a fresh detector with the same seed reproduces the same first-call sequence.
