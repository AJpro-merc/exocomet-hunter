    48. Experiment Registry¶

    Status: reflects repo state as of 2026-09-16, commit 01c2051.

    Real experiments that have actually run, with commit/config/dataset/outputs traced where recorded. Fields left UNKNOWN were not captured at the time the experiment ran (this project did not have a provenance manifest — see 52_scientific_state_versioning.md). Machine-readable mirror: docs/specification/registry/experiments.yaml.

    EXP-001 — Six-event KIC 3542116 validation¶

    • Date: 2026-09-14 through 2026-09-15 (re-run after A1/A4 fixes; exact final re-run timestamp not separately recorded).
    • Description: Re-detect all six published Rappaport et al. (2018) exocomet transit epochs in KIC 3542116 using scripts/run_validation.py / exocomet validate against config/validation_targets.yaml.
    • Commit: UNKNOWN exact commit for the final passing run; current HEAD (01c2051) contains the code that produces this result per the README's own recovery table.
    • Dataset: Real MAST Kepler long-cadence photometry for KIC 3542116 (author="Kepler").
    • Config: config/thresholds.yaml as of the post-A4 state (delta_bic_threshold=10.0, tau_over_sigma_threshold=1.0).
    • Outputs: Console pass/fail table (cmd_validate in cli.py); the specific recovered epochs and depths are recorded in README.md's recovery table (epoch errors 0.029–0.184 d across the six dips).
    • Status: VALIDATED.

    EXP-002 — B1 depth-offset measurement¶

    • Date: 2026-09-15.
    • Description: Measured the systematic ~77–78% depth ratio (recovered vs. published) across all six KIC 3542116 dips; tested three hypotheses (baseline contamination H1, fitted-vs-observed depth H2, detrending absorption H3) plus a combined H1+H3, on both a synthetic sanity check and real cached photometry.
    • Commit: Work performed within the 2026-09-15 session (Session Log 2026-09-15 §6); scripts/measure_depth_offset.py (626 lines) is the tool. Exact commit hash for the tool's landing is UNKNOWN from available records; current HEAD contains the script.
    • Dataset: Real, previously cached KIC 3542116 FITS files under data/raw/mastDownload/ (offline mode, --source cache, no network); one known-corrupt cached file (65536-byte truncation) was auto-skipped.
    • Config: Default config/thresholds.yaml at the time; also a baseline-window sweep (2.06 d to 20 d) as a secondary sensitivity test.
    • Outputs: docs/research_log/006-depth-offset-investigation.md, including full per-dip and per-hypothesis ratio tables.
    • Status: VALIDATED as a measurement (the numbers are real and traced); the underlying scientific question (why the residual 10–15% gap exists) remains OPEN — see 49_negative_results.md and 53_threats_to_validity.md.

    EXP-003 — A4 mirror-image adversarial test¶

    • Date: 2026-09-15.
    • Description: Generated two synthetic events as exact time-mirrored images of each other (same depth, noise, and total duration; only ingress/egress direction flipped) to test whether ΔBIC alone or τ/σ carries direction information for the flagging decision.
    • Commit: Landed as part of the A4 fix; figure at results/figures/tail_direction.png produced via viz.plots.plot_tail_direction.
    • Dataset: Fully synthetic (not real photometry) — this is a controlled, reproducible unit-test-style experiment, not a survey run.
    • Config: N/A (synthetic construction, not read from thresholds.yaml).
    • Outputs: docs/research_log/007-delta-bic-is-direction-blind.md, with the exact numeric result table (ΔBIC 151 vs 201, τ/σ 4.15 vs 0.23).
    • Status: VALIDATED — this is the evidentiary basis for CLAIM-002 in 43_scientific_claims_registry.md.

    EXP-004 — Cross-cadence injection-recovery check (A1/A2 fix verification)¶

    • Date: 2026-09-14.
    • Description: The same synthetic injected comet transit was recovered at matching epoch and τ/σ from both a 120 s-cadence and a 1800 s-cadence version of the same time span, verifying that day-based (not cadence-count-based) window configuration produces cadence-independent results.
    • Commit: Landed alongside the A1/A2 fixes, 2026-09-14.
    • Dataset: Synthetic (no network).
    • Config: Post-A1 config/thresholds.yaml (days-based windows).
    • Outputs: tests/unit/test_cross_cadence.py (a permanent regression test, not a one-off report).
    • Status: TESTED, VALIDATED (runs on every pytest tests/unit invocation).

    EXP-005 — Real ingestion pipeline end-to-end proof (GitHub Actions)¶

    • Date: 2026-09-15 (into early 2026-09-16 per commit timestamps).
    • Description: Two escalating real, non-offline test runs against actual MAST data (1 target, then 2 targets, proving resume-after-kill works), followed by a real workflow_dispatch run on GitHub Actions infrastructure (3-minute budget, 1 target), then — after DATA_REPO_TOKEN was added — a full real hourly-cron-shaped run confirmed to push actual output (ledger.jsonl, a Kepler parquet extract, results) into AJpro-merc/exocomet-hunter-data.
    • Commit: afa4bb2 (initial ingest.py + workflow landing), then 01c2051 (current HEAD; control-star matching fix and the confirmed live token-enabled run per Session Log 2026-09-15 §12).
    • Dataset: Real MAST data for KIC 1161345 (single-target test) and the 23 Kepler + 10 TESS hardcoded seed targets thereafter.
    • Config: config/thresholds.yaml at commit 01c2051; ingestion parameters --time-budget-minutes 25, default --max-attempts 3.
    • Outputs: The cloned exocomet-hunter-data repository itself — directly re-verified (2026-09-16): ledger.jsonl contains 33 lines (unique target/mission pairs), 25 with status="success", 8 with status="failed".
    • Status: VALIDATED (the pipeline demonstrably ran and pushed real data successfully at least twice — 2026-09-15 17:50 UTC and 21:07 UTC, per the sibling 23_automation.md section's live gh run list query); continuous unattended operation over time is NOT VALIDATED — the same query shows the two most recent scheduled runs (2026-09-16, 00:05 and 05:50 UTC) both failed on a known, already-locally-fixed-but-uncommitted bug (59_error_taxonomy.md ERR-006; see CLAIM-105 in 43_scientific_claims_registry.md).

    EXP-006 — KIC 1161345 anomalous flag-rate observation¶

    • Date: 2026-09-15/16, two independent real MAST fetches.
    • Description: KIC 1161345, assumed "quiet" (part of KEPLER_HOST_STARS), produced 43 flagged candidate events out of roughly 260 detected events across two separate real fetches — an unusually high rate for a supposedly quiet star.
    • Commit: Observed during the scripts/ingest.py real-MAST test runs, 2026-09-15/16.
    • Dataset: Real Kepler long-cadence photometry for KIC 1161345.
    • Config: config/thresholds.yaml at the time of the observation (post-A4).
    • Outputs: A real candidate-record sample from this run is quoted in 76_appendices.md; the star has not yet been run through scripts/vet_host_list.py for a direct verdict.
    • Status: Recorded as an open finding, not yet resolved. See 49_negative_results.md EXP-006 discussion.

    Injection-recovery / completeness sweeps — STATUS: STALE, not a tracked experiment ID here¶

No experiment ID is assigned here because the run that would need re-doing has not happened yet with the current code; treat the README numbers as historical, not current, per CLAIM-006 in 43_scientific_claims_registry.md.
